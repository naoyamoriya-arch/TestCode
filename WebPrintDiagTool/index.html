2 印刷ダイアログの表示テスト

【操作手順】

  1. 下の「印刷テストを開始する」ボタンを押してください。
  2. 印刷ダイアログ（プリンタ選択画面）が表示されるのをお待ちください。
  3. ダイアログが表示されたら、印刷はせずに「キャンセル」を押して閉じてください。

※プレビュー画面など、一部の環境ではセキュリティ制限によりボタンが反応しない場合があります。その場合はファイルをPCに保存（ダウンロード）してから、ブラウザで開いて実行してください。

ダイアログを呼び出せませんでした。ローカルPCに保存してから実行してください。

✓ 印刷ダイアログテストが完了しました。

システムでの自動計測時間は 0 秒でした。

3 簡易レポートの出力

問診とテストが完了したら、以下のボタンからレポート（テキストファイル）をダウンロードし、サポート窓口へ送付してください。

※すべての問診項目とテストを完了してください。

✓ レポートをダウンロードしました。サポート窓口へご提供ください。

4 詳細調査ツールのダウンロード（高度な調査用）

簡易レポートだけでは原因が特定できない場合や、サポート窓口から指示があった場合は、以下のツールをダウンロードしてPC上で実行してください。

【実行手順】

  1. 下のボタンを押し、ツールをダウンロードします。
  2. ダウンロードされた PrintDiagTool.ps1 を右クリックします。
  3. メニューから「PowerShell で実行」を選択します。（※実行には管理者権限が必要です）
  4. 画面の指示に従うとZIPファイルが作成されます。そのZIPファイルをサポート窓口へご提供ください。

✓ ツールをダウンロードしました。手順に従って実行してください。
